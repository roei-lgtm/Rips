# Production gaps — this is a local demo

- Real authentication, secure sessions, verified admin authorization and tenant boundaries. Demo role header is an explicit local stub.
- Jurisdiction-specific legal review, age/geo gating, terms and compliance approval before any real-money collectible product.
- Third-party asset licensing and review of category names. Current artwork and symbols are original alternatives.
- Audited RNG, outcomes and inventory valuation; risk controls and rate limiting. Crypto randomness alone is not a production audit.
- Real wallet custody, payments, reconciliation, refunds, anti-fraud, withdrawal policies and PCI scope. Never connect demo top-ups directly to payment providers.
- KYC/AML provider interfaces and approved identity workflows.
- Durable fulfillment integration, validated addresses and real 3PL/carrier services; no actual label generation is present.
- Postgres migration, multi-instance concurrency and load testing. SQLite is for this local demo.
- Database backups and restoration, migration upgrade policy, observability, alerting and incident recovery.
- Independent accessibility audit, performance measurements on mobile hardware and review against the missing approved visual references.
- Replace illustrative original demo cards and valuations with licensed, reconciled inventory if that is separately authorized.
